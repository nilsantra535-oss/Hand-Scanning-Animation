# Hand Scanning Animation 🖐️✨

A modern, sleek **Hand Print Scanning Animation** built purely with **HTML5** and **CSS3**. It features glowing neon visual effects, scanning laser lines, biometric point overlays, and smooth keyframe animations.

---

## 🚀 Features

* **Pure CSS Animations:** Smooth laser scanning, line reveals, and glowing pulse effects using `@keyframes`.
* **Neon Glow Aesthetics:** Futuristic cyan `#3fefef` cyberpunk theme with custom CSS drop-shadows.
* **Blinking Status Text:** Flashing "Hand Print Scanning" indicator steps.
* **Responsive Layout:** Centered flexbox interface designed for modern dark-mode displays.
